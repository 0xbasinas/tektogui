# {{title}}

A small Tekto app, generated by `tekto new`.

You need a Rust toolchain and a local tektogui checkout (this app depends on it by path).

## Run headless (no window)

```bash
cargo run -- --headless --out {{package}}.png
```

This writes a PNG and prints the scene tree. You should see a stable `window#1` and the text `Hello from Tekto`.

## Open a window

```bash
cargo run
```

While it is running, the dev server is up. From the tektogui repo, in another terminal:

```bash
cargo run -p tekto-cli -- tree
cargo run -p tekto-cli -- screenshot shot.png
cargo run -p tekto-cli -- patch 4 --text "Hello from an agent"
```

(`4` is an id from `tekto tree`; use the id you actually see.)

## TypeScript sketch

`src/app.tsx` is a JSX view of the same layout. Install the local package links and check it with npm, pnpm, or bun:

```bash
npm install
npm run typecheck
npm run build:web
npm run build:desktop
```

The build commands write a browser ES module and a desktop QuickJS bundle to `dist/`. Set `ESBUILD` to an esbuild executable if it is not on `PATH`.

To run the sketch, from the Tekto checkout use `cargo run -p tekto-cli --features quickjs -- dev --js <path-to-app>/src/app.tsx`, or `node packages/wasm/dev.js <path-to-app>/src/app.tsx` for the browser. Both need esbuild on `PATH` or in `ESBUILD`.
